# Notion Workspace Maintainer

帮助助手维护 Notion 页面、数据库视图和布局的 Skill。这是操作说明，不是独立运行的网站或程序。

## 第一次使用

从 [SKILL.md](SKILL.md) 开始。无需 npm 或构建；所需连接器由使用这个 Skill 的助手提供。

下载仓库，把 SKILL.md、agents 和 references 保持在同一技能目录中，再由支持 Skill 的助手加载。连接 Notion 后，先给出一个具体页面和小任务，检查结果再扩大范围。公开版本不含私人工作区映射。源码文件是最新编辑入口；仓库 ZIP 是历史打包快照，使用前核对版本。
